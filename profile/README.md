## 📅 스터디 규칙

### 🕒 정기 모임

| 항목      | 내용                          |
| --------- | ----------------------------- |
| 시간      | 매주 화요일 오전 11시         |
| 장소      | 기본 온라인 (월 1회 오프라인) |
| 소요 시간 | 약 1시간 내외                 |

#### 진행 방식

**💡 Code Review**

- 각자 풀이한 문제 중 가장 공유하고 싶은 문제 1개 발표
- 접근 방식, 트러블 슈팅, 개선 방향 공유

**🔍 Troubleshooting**

- 실패했거나 비효율적이었던 코드 리뷰
- 다양한 풀이 방식과 최적화 방법 토론

### 📝 문제 풀이 및 제출

#### 문제 선정

- 매주 **공통 문제 2개 + 자유 문제 1개**
- 공통 문제는 스터디장이 GitHub Issue로 등록
- 자유 문제는 각자 원하는 문제 선택

#### 제출 규칙

- 총 3문제를 풀이 후 Pull Request 제출
- 스터디 시작 전까지 제출 완료

### ☕ 벌금 제도 (Coffee Rule)

목표를 달성하지 못하면 팀원들의 카페인을 책임집니다.

- 미달성 문제 1개당 = 커피 1잔
- 편의를 위하여 미달성 문제 1개당 5천원 적립

## 🔄 스터디 운영 플로우

```text
화요일
→ 스터디장이 공통 문제 2개를 GitHub Issue로 등록

스터디 전까지
→ 공통 문제 2개 + 자유 문제 1개 풀이
→ Pull Request 제출

화요일 오전 11시
→ 코드 리뷰 및 풀이 공유
```
