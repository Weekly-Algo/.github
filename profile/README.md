## 📅 정기 모임

| 항목 | 내용 |
| :--- | :--- |
| 시간 | **매주 월요일 오후 9시** |
| 장소 | 기본 온라인, 월 1회 오프라인 |
| 소요 시간 | 약 1시간 |
| 주간 목표 | **공통 문제 2개 + 자유 문제 1개** |
| 제출 기한 | 스터디 시작 전까지 Pull Request 제출 |

### 모임에서는 이렇게 나눕니다

**01. 풀이 공유**

- 각자 풀이한 문제 중 가장 공유하고 싶은 문제 1개 발표
- 문제의 핵심과 접근 방식 설명

**02. 코드 리뷰**

- 구현 과정에서 겪은 오류와 해결 방법 공유
- 서로의 코드에서 개선할 부분과 새로운 접근 방식 발견

**03. 함께 해결**

- 실패했거나 비효율적이었던 코드 리뷰
- 다양한 풀이 방식과 최적화 방법 토론

## 📝 문제 풀이와 제출

### 문제 선정

- **공통 문제 2개:** 스터디장이 GitHub Issue로 등록
- **자유 문제 1개:** 각자 원하는 문제 선택

### 제출 규칙

- 매주 총 3문제 풀이 후 **Pull Request 제출**
- **월요일 오후 9시, 스터디 시작 전까지** 제출 완료
- 모임에서 공유할 문제 1개 준비

## 🔄 한 주의 운영 흐름

| 단계 | 할 일 |
| :--- | :--- |
| **문제 등록** | 스터디장이 공통 문제 2개를 GitHub Issue로 등록 |
| **개별 풀이** | 공통 문제 2개와 자유 문제 1개 풀이 |
| **모임 전 제출** | 스터디 시작 전까지 Pull Request 제출 |
| **월요일 오후 9시** | 코드 리뷰, 풀이 공유, 트러블슈팅 |

## ☕ Coffee Rule

목표를 달성하지 못하면 팀원들의 카페인을 책임집니다.

> **미달성 문제 1개당 커피 1잔**<br/>
> 정산 편의를 위해 문제 1개당 **5,000원**을 적립합니다.
